# 工業工程圖與計算工具

保留柏拉圖與製程能力圖，再加八個計算工具。所有示例為合成資料。

| 工具 | 公式與單位 |
| --- | --- |
| 勞動生產力 | 產出 ÷ (人數 × 每人工時)，輸出件/人時等單位 |
| OEE | A=運轉/計畫時間；P=理想週期×總件數/運轉時間；Q=良品/總件數；OEE=A×P×Q |
| 產線平衡 | Σ已分配站負荷 ÷ (站數 × 週期)，並顯示每站空閒 |
| 效率／效能 | 本工具效率=(實際產出/實際投入)/(計畫產出/計畫投入)；效能=實際產出/目標產出 |
| 需求節拍 | 淨可用分鐘 × 60 ÷ 同期間需求，輸出秒/件 |
| 工作量時間估算 | (Σ每次分鐘×次數 + 準備分鐘) × (1+緩衝%/100) |
| 產能負荷 | Σ數量×每件加工分鐘 ÷ 淨可用分鐘，顯示時間缺口 |
| 工作日計画日曆 | 順序分配任務分鐘，每日不超額，跳過非工作日與手動休假 |

OEE 的 planned_minutes 和 stop_minutes 是分鐘；ideal_cycle_seconds 是秒/件，程式轉換後計算。不包含生產的區間（總件數為 0）無法定義良品率，本版提示錯誤。性能超過 100% 時需檢查理想週期與單位。

日曆的 workdays 是 0（週一）至 6（週日），excluded_dates 使用 YYYY-MM-DD。每天的可用分鐘應先扣除休息與固定活動。任務按輸入順序排程，可跨日分拆；不處理平行資源、相依網絡、自動國定假日或提醒。最多 200 個工作日。完成日是估算結果，非承諾。

產能表假設單一共用資源，應把可用時間與需求範圍保持一致；未納入換線、停機及不良率。效率與效能是本工具的明示操作定義，不代表所有課本使用相同定義。OEE、目標效能、平衡效率不可當成同一個指標。多列計算表可在畫面捲動，圖片匯出以當前可見表格為準；完整輸入可保存 JSON。

來源：
- https://www.oee.com/calculating-oee/
- https://www.lean.org/lexicon-terms/takt-time/
