# 學習圖表擴充（主工作台 31–50）

保留原來的 30 種圖形，新增 20 個學習用指令。這個資料夾提供範例、驗證與版面；沿用主工作台的 Plotly、20 色、黑白底、SVG／PNG／PDF 輸出。

## 怎麼用

1. 主工作台按「選擇指令架構」，選一個學習圖。
2. 按「範例」取得正確欄位，或「複製 AI 提示詞」交給你的 AI 整理資料。
3. 切到「貼上指令」，貼入**單一 JSON 物件**，按「產生圖形」。不接受任意 JavaScript／Python。
4. 可以繼續用「點選填寫」；節點、步驟等複雜欄位保留 JSON 格式。
5. 問答卡先看問題，把滑鼠停在卡片文字上才顯示答案。手機長按／懸停支援依瀏覽器而異；不保證等同桌面操作。
6. PDF 仍透過原本的列印視窗「另存為 PDF」。

## 適用情境

| 圖形 | 用途 |
|---|---|
| 概念圖 | 用連接詞描述概念關係 |
| 因果鏈 | 逐步整理原因與結果 |
| 決策樹 | 條件判斷、選擇解題方法 |
| 比較矩陣 | 多個概念採同一維度比較 |
| 流程圖 | SOP、步驟與順序 |
| 公式關係圖 | 公式、用途與易錯點 |
| 層級分類圖 | 支援多層知識分類 |
| 考前總覽 | 重點、公式、易錯點分區 |
| 魚骨原因圖 | 整理問題可能原因，不能單靠圖確認因果 |
| 集合重疊圖 | 兩集合共同與不同特徵；圓面積不代表數量 |
| 四象限學習圖 | 理解程度與重要程度的定位 |
| 事件時間軸 | 依輸入順序呈現日期與事件；不推測日期或比例間距 |
| 循環學習圖 | 展示循環步驟 |
| 層級金字塔 | 從總結到理由與細節 |
| 康乃爾筆記圖 | 提問、內容、摘要 |
| KWL 知識盤點 | 已知、想知道、學到的內容 |
| 主動提取問答卡 | 先回想，再查看答案 |
| 間隔複習排程 | 自訂天數；不自動安排提醒或計算最佳間隔 |
| 學習甘特圖 | 任務起點、持續時間及重疊 |
| 論證結構圖 | 主張、理由、證據與反駁 |

所有內建內容都是合成示例，請依教材修改並確認來源。完整可複製格式見根目錄 `CHART_FORMATS.md`，或 `examples/charts-50.json`，每次取一個物件。

## 限制

- 圖表只整理你提供的內容，不執行 AI 推論、算式求值、日期推測或研究結論。
- 概念圖最多 40 個節點、80 條關係；端點必須存在且 id 唯一。
- 樹圖最多 80 節點、8 層；長內容宜拆成多張圖。
- 一般學習文字最多 200 字；摘要及答案最多 500 字。
- 新增圖表沿用 Plotly CDN，因此需要網路；新增擴充沒有另一套圖表引擎。
- 長圖縮放後文字可能較小，適合下載 SVG 放大阅读。
- 桌面懸停的問答答案不會出現在靜態圖片；靜態圖片保留問題，JSON 保留完整答案。

## 驗證

`node tools/check-learning.cjs`：檢查 50 種範例與表單資料來回轉換、49 個 Plotly 設定、11 種非法資料及新增 20 圖的黑底設定。心智圖走原有 SVG 路徑。這些檢查不等同實際瀏覽器繪圖與下載測試。
