# 商業與時間管理（91–100）

| 工具 | 用途／計算 |
| --- | --- |
| 重要／緊急矩陣 | X=緊急、Y=重要，0–100；高重要高緊急先做，其餘排程、委派或刪減 |
| 每日時間預算 | 可用時間 − Σ任務分鐘 − 保留時間；負值代表超額 |
| 價值／時間排序 | 主觀價值分數(0–10) ÷ 分鐘；不能取代期限與必要性 |
| 番茄鐘工時計畫 | 按轮次加專注與休息，長休息取代短休息；最後一輪不加休息；不是計時器 |
| 時間投資回收 | 淨節省=(每次節省−每次維護)×次數−初始投入；回收次數為向上取整 |
| 會議人時 | Σ個人參與分鐘/60；不是會議歷時、薪資或金錢成本 |
| 期限倒排 | 假設截止日整天可用，按任務順序向前排到最遲開始日 |
| 關鍵路徑 CPM | ES/EF 正推、LS/LF 逆推，浮時=LS−ES；★ 表示零浮時，不一定只有一條關鍵路徑 |
| 計畫／實際差異 | 實際−計畫；差異%=(實際/計畫−1)×100% |
| Little 定律 | W=L/λ；平均在製量、平均產出率需一致流程邊界與觀察期間，長期穩定平均 |

範例都是合成資料。倒排不含時刻、自動假日、平行資源；請在 excluded_dates 手動設定休假。CPM 允許可平行任務，未考慮共用人力／設備、休假或緩衝；工期是輸入單位的連續時間，不能直接視為有假日的日曆交期。Little 定律不能保證單件交期。多列計算表可捲動，匯出以可見畫面為準；完整資料可保存 JSON。

Little 定律參考 MIT 課程：https://web.mit.edu/1.041/www/lectures/L8-queuing-models-2026sp.pdf
