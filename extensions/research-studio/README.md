# Research Studio｜獨立研究擴充

入口：`extensions/research-studio/index.html`。使用主程式同一個前端便利密碼，不提供真正的伺服器認證。

此資料夾在獨立頁面執行，不載入主程式 charts.js/builder.js，也不修改原本 30 種 JSON 格式。新增引擎只在此頁按「產生圖形」時載入。主頁只增加入口及可移除的專業外觀層。

## 14 個架構

| 引擎 | 圖形 | 用途 |
|---|---|---|
| ECharts | 誤差棒、森林圖 | 估計值與提供的區間 |
| ECharts | 啞鈴、柏拉、管制圖 | 前後比較、問題次數、品質觀測 |
| ECharts | 關係網、階層樹、日曆熱力 | 知識結構與學習紀錄 |
| Mermaid | 流程、循序、甘特、狀態、類別、ER | 研究流程、計畫及系統設計 |

這些是人工設計的轉接器與範例；沒有從網路任意複製圖表程式。引擎來源與授權列在 THIRD_PARTY.md。

## 報告設計

- 學術藍橙、低彩度商務、黑白列印三套風格。
- 白底、清晰字體、淡色網格、標題層級。以標記／線型輔助區分，仍需自行檢查目標期刊與列印品質。
- SVG 向量與 3× 像素 PNG；完整匯出標題、副標、圖說、資料來源。
- 900×520、1200×675、800×800 為圖形區尺寸，匯出會另加文字邊界。
- 3× 像素不代表檔案帶有 300 DPI 中繼資料；可在排版軟體按需求設定實際印刷尺寸。
- 可用瀏覽器列印／存 PDF；大型圖需在列印對話框選橫向、調整縮放。
- 輸入 JSON 後按「讀取指令欄位」同步圖說，再按「產生」。右側文字是圖說的編輯來源。

## 數據原則

區間／誤差圖的 lower、estimate、upper 必須一致。CI/SD/SE 的意義與樣本數需寫入圖說，程式不推斷。森林圖只呈現提供的效果量與區間，不執行統合分析。管制圖需提供合法 CL/LCL/UCL，不會將一般平均數自動當成管制界限。柏拉圖只計算排序與累積比例。階層樹不是聚類樹。所有範例為合成資料。

## 移除與回復

刪除主頁的研究入口即可不顯示擴充；刪除 professional.css/professional.js 的引入即可移除外觀層。保留主程式原有檔案。資料夾沒有覆寫全域主程式狀態（外觀層包裝 chartConfig 只改樣式，不改資料）。

## 驗證限制

已用 Node 驗證轉接器、合成範例、無效區間與日期等；瀏覽器渲染、Mermaid 引擎載入與 PNG 匯出尚需實機驗證。不得因此宣稱已達特定期刊投稿規格。

## 思考圖與筆記擴充

`thinking.js` 新增 16 個架構：概念、因果循環、交換、Why 深挖、結論—理由—證據、2×2 比較矩陣、文氏、層級金字塔、魚骨，以及任務子彈、問題解決、卡片盒、提取練習卡、反思行動、三層、三重點筆記。合計此工作室 30 個架構，原主工作台仍為 30 種。

來源：依使用者提供的功能清單設計通用模板，未聲稱核實相關書籍的作者歸屬或課程講次。卡片盒不等於記憶卡；概念圖的邊需有關係詞，因果循環用正負方向，且圖形不是因果證據。

外觀設定由 `../appearance.js` 提供 20 色與黑白圖表背景，輸出保留底色。原生 SVG 模板不需下載外部引擎，ECharts/Mermaid 架構仍需網路。
