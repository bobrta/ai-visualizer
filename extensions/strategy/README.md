# 商業與表達架構（10 個）

| 架構 | 適合用途 |
| --- | --- |
| PREP | 主張、理由、例證與行動 |
| SWOT | 內部優劣勢與外部機會威脅 |
| TOWS | 把 SWOT 轉成四種策略 |
| SCQA | 情境、衝突、問題、答案 |
| BMC | 九區塊商業模式 |
| VPC | 顧客任務、痛點、收穫及對應解方 |
| PESTEL | 六類外部環境因素 |
| 波特五力 | 產業竞争結構 |
| AIDA | 注意、興趣、渴望、行動 |
| OKR | 目標與可量測關鍵成果 |

在主工作台選架構、套用範例、修改表單或 JSON，再按產生圖形。PNG、SVG、PDF 沿用原有下載。畫布為自製視覺化版面，不宣稱是第三方官方模板。所有內容需依實際資料修改。

新畫布列表欄位每欄 1–4 項，每項最多 80 字。區塊高度按文字行數調整；內容很多時可放大局部。OKR 的 direction 是 increase 或 decrease，target 必須在相對 baseline 的正確方向。進度以 (current-baseline)/(target-baseline) 計算，可以低於 0% 或超過 100%，並非自動績效評分。框架不替你產生研究結論或市場分析。
