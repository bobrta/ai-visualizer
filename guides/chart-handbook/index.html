三步驟開始

  1. 寫下你要回答的問題：分類、關係、比較、趨勢，還是計算時間？
  2. 找到圖表後，複製 JSON 直接修改，或複製 AI 指令並附上自己的資料。
  3. 把一個 JSON 物件貼進工作台「貼上指令」，產生後核對單位與來源。

優先用 2D 圖比較數字；概念圖要有關係詞。數值不足先補資料，不要讓 AI 虛構。報告加上圖說與來源。
