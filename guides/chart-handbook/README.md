工作台左側點「選圖・推薦書・指令指南」即可開啟網頁。先選用途，再找圖；每張圖可複製範例 JSON、複製 AI 指令，或點「在工作台使用」載入該類型範例。這是獨立指南資料夾，不增加付費 API。

## 最快操作

1. 先写一句你要回答的問題：例如「哪些觀念重要但我還不熟？」
2. 選四象限，給兩個軸明確定義及 0–100 的評分方式。
3. 有數據直接修改 JSON；只有教材就把資料和指南指令交給 AI。
4. 把 AI 回覆的一個 JSON 物件貼到 App「貼上指令」，按產生。
5. 檢查數值、來源、單位；調字級、填圖說，再匯出 SVG／PNG／PDF。

範例都是合成資料。圖表外觀改善不等於研究結論成立。四象限評分是你的定義或實測，不能當成工具自動診斷。
