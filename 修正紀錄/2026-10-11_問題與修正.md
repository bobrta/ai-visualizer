## 驗證

- 既有 21 組規則／計算／版面檢查全部通過，包括 100 種格式、99 種 Plotly 設定與表單 round-trip。
- 新增 `npm run test:editor`：37 項 DOM 整合檢查通過，涵蓋直接進入、草稿、undo/redo、metadata、匯出狀態、原生研究 SVG。
- DOM 測試中的 Plotly 與下載 API 為 mock；PDF 單元檢查覆蓋有／無 MIME 參數的 SVG Data URL，並用 `pdfinfo` 驗證輸出的 PDF 結構與 A4 尺寸。
- GitHub Actions Chromium 模擬環境的 36 項瀏覽器可靠性檢查通過，實際下載圖表與心智圖 PDF，並驗證 PDF 標頭、A4 頁面尺寸、桌面／手機導覽及研究工作室渲染。
- `verify`、Windows、macOS 與 Chromium visual 工作全部通過。
- `git diff --check` 與 JavaScript 語法檢查通過。
